1. Akses SSH & Console

Terminal SSH (Password) 
ssh -p <PORT> root@<nama-vm>.boxd.sh

Klik tombol Set Pass di kartu VM untuk atur password & dapatkan port SSH langsung.

Transfer File (SCP) 
scp -P <PORT> script.py \
  root@<nama-vm>.boxd.sh:/root/
Klik tombol >_ Console di kartu VM untuk menjalankan command langsung dari browser.

2. Deploy MicroVM

Lewat Dashboard

Buka tab Machines lalu klik + Deploy VM untuk pilih akun, region, dan ukuran vCPU/RAM.

Lewat CLI 
boxd machine new my-vm \
  --vcpu 2 --memory 4G --region fra --shared
Gunakan --shared (atau centang Share with Org) bila memakai ORG key agar VM bisa dikontrol di konsol.

3. Hemat Saldo & Always-On

  • Running: Dihitung per detik untuk vCPU, RAM, dan storage.
  • Hibernated / Stopped: Biaya vCPU & RAM $0, hanya kena biaya storage NVMe.
  • Mode Sepuasnya: Pilih preset Sepuasnya (Always-On) saat deploy atau lewat tombol Kelola di kartu VM untuk mematikan auto-sleep, membuka akses API/webhook, dan mengaktifkan Auto-Update.
Gunakan tab Sepuasnya & Spek di menu Kelola untuk ubah timer idle atau resize vCPU/RAM kapan saja tanpa hapus VM.

4. Routing Web

Endpoint HTTPS 
https://<nama-vm>.<region>.boxd.sh

Jalankan server di port 80 atau 3000 dalam VM agar trafik langsung diteruskan ke URL HTTPS otomatis.

Subdomain & Port Forward Kelola → Port & Web

Tambah subdomain HTTPS khusus seperti api.<vm> atau buka hingga 3 port TCP/UDP langsung dari menu Kelola.

5. Perintah Boxd CLI

Perintah Fungsi
boxd machine ls Daftar microVM di home region
boxd machine start <name> Nyalakan VM yang standby atau hibernated
boxd machine stop <name> Hentikan VM untuk menyetop biaya vCPU & RAM
boxd machine ssh <name> Masuk SSH ke VM tanpa ketik port manual
boxd machine exec <name> -- <cmd> Jalankan satu command di dalam VM
boxd org usage Cek pemakaian compute & saldo organisasi
