1. Akses & Konek (SSH / Console)

Tiap microVM punya port SSH publik khusus dan web console instan:

Terminal SSH (Langsung dari HP / Laptop) 
ssh -p <PORT> root@nyc.boxd.sh
Contoh instans demo-vm: port 22001
Tips Web Console: Klik tombol >_ Console di kartu instans buat buka terminal langsung di browser tanpa perlu install client SSH.
Upload / Download File (SCP) 
scp -P <PORT> script.py root@nyc.boxd.sh:/root/

2. Cara Deploy MicroVM

Bikin instans baru bisa lewat 2 cara gampang:

A
Lewat Dashboard Web:

Buka tab Machines → klik tombol Deploy MicroVM di pojok kanan atas → tentukan vCPU, RAM, dan disk.

B
Lewat Terminal CLI: 
boxd machines create --name my-vm --vcpu 2 --ram 4096 --disk 50
Instans jalan di atas Firecracker KVM, siap pakai dalam 2–5 detik.

3. Trik Hemat Saldo (Micro-Metering)

Sistem billing Boxd dihitung per-detik (pay-as-you-go):

  • Status RUNNING: vCPU ($0.0470/hr) + RAM ($0.0140/GB-hr) + Storage.
  • Status HIBERNATED / STOPPED: vCPU & RAM $0 (GRATIS)! Cuma bayar storage NVMe ($0.0001/GB-hr atau ~Rp 15/hari).
  • Cara Irit: Kalau selesai testing, klik tombol ⏸ Pause atau ■ Stop. Saldo lu bakal awet berbulan-bulan.

4. Web Domain & Routing HTTP

Tiap VM otomatis dapet alamat publik gratis:

URL Publik Otomatis 
https://<nama-vm>.nyc.boxd.sh

Tinggal jalankan web server di dalam VM (port 80 atau 3000), traffic otomatis di-forward tanpa perlu setting Nginx manual.

5. Cheatsheet Command Boxd CLI

Command Fungsi
boxd machines list Cek status semua microVM aktif & hibernated
boxd machines start <name> Nyalakan kembali VM yang lagi standby / hibernated
boxd machines stop <name> Matikan VM buat stop charge vCPU/RAM (hemat saldo)
boxd machines ssh <name> Langsung SSH ke instans otomatis tanpa ketik port
boxd machines exec <name> -- <cmd> Eksekusi satu perintah shell tanpa login SSH manual
boxd orgs usage Lihat rincian pemakaian saldo & telemetri akun
