1. Akses SSH & Console

Terminal SSH 
ssh -p <PORT> root@<region>.boxd.sh
Region tersedia: fra.boxd.sh atau nyc.boxd.sh
Transfer File (SCP) 
scp -P <PORT> script.py root@<region>.boxd.sh:/root/
Klik tombol >_ Console di kartu VM untuk menjalankan command langsung dari browser.

2. Deploy MicroVM

Lewat Dashboard

Buka tab Machines lalu klik + Deploy VM untuk pilih akun, region, dan ukuran vCPU/RAM.

Lewat CLI 
boxd machine new my-vm --vcpu 2 --memory 4G --region fra --shared
Gunakan --shared (atau centang Share with Org) bila memakai ORG key agar VM bisa dikontrol di konsol.

3. Hemat Saldo

  • Running: Dihitung per detik untuk vCPU, RAM, dan storage.
  • Hibernated / Stopped: Biaya vCPU & RAM $0, hanya kena biaya storage NVMe.
  • Tips: Aktifkan Auto-Suspend saat deploy atau klik Hibernate setelah selesai pakai.

4. Routing Web

Endpoint HTTPS 
https://<nama-vm>.<region>.boxd.sh

Jalankan server di port 80 atau 3000 dalam VM agar trafik langsung diteruskan ke URL tersebut.

5. Perintah Boxd CLI

Command Fungsi
boxd machine ls Daftar microVM di home region
boxd machine start <name> Nyalakan VM yang standby atau hibernated
boxd machine stop <name> Hentikan VM untuk menghentikan charge vCPU/RAM
boxd machine ssh <name> Masuk SSH ke VM tanpa ketik port manual
boxd machine exec <name> -- <cmd> Jalankan satu command di dalam VM
boxd org usage Cek pemakaian compute & saldo organisasi
